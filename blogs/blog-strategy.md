## 1. Blog Objectives

### Primary Goals:
- **Rank for target keywords** identified in keyword research strategy
- **Generate nursing registrations** through informative content
- **Attract healthcare facility clients** with employer-focused articles
- **Establish authority** as South Africa's healthcare staffing expert
- **Drive organic traffic** to main service pages

### Target Audiences:
1. **Nursing Job Seekers** (60% of content)
   - Registered nurses, enrolled nurses, caregivers
   - Looking for locum or permanent placements
   - Need guidance on SANC registration, CV preparation, career progression

2. **Healthcare Employers** (40% of content)
   - Hospital administrators, clinic managers
   - Need staffing solutions, compliance guidance
   - Looking for reliable, verified healthcare professionals

## 2. Keyword Strategy

### 2.1 Keyword Distribution Per Blog Post

**Primary Keyword:** 1 per blog post
- Use in: Title, H1, first paragraph, 2-3 times in body, meta description, URL
- Density: 1-2% of total content

**Secondary Keywords:** 3-5 per blog post
- Use in: H2/H3 headings, body content, image alt text
- Density: 0.5-1% each

**Long-tail Keywords:** 2-3 per blog post
- Use naturally in body content, FAQs, subheadings
- Focus on search intent alignment

### 2.2 Keyword Placement Priority

1. **Title Tag** (60 characters max) - Include primary keyword
2. **Meta Description** (155-160 characters) - Include primary keyword + CTA
3. **URL Slug** - Include primary keyword, use hyphens
4. **H1 Tag** - Include primary keyword
5. **First 100 Words** - Include primary keyword in first paragraph
6. **H2/H3 Tags** - Include secondary keywords
7. **Body Content** - Natural keyword integration throughout
8. **Image Alt Text** - Include relevant keywords
9. **Internal Links** - Use keyword-rich anchor text
10. **FAQ Section** - Include question-based long-tail keywords

## 3. Content Structure Standards

### 3.1 Standard Blog Post Structure

```
1. Hero Section
   - H1: Primary keyword + compelling title
   - Meta description
   - Featured image with optimized alt text
   - Author info and publish date

2. Introduction (100-150 words)
   - Hook the reader
   - State the problem/question
   - Include primary keyword in first 100 words
   - Preview what reader will learn

3. Main Content (1,200-2,000 words)
   - H2 sections with secondary keywords
   - H3 subsections for detailed topics
   - Bullet points, numbered lists for scannability
   - Real examples and data where possible
   - Internal links to relevant service pages

4. FAQ Section (5-8 questions)
   - Question-based long-tail keywords
   - Concise, valuable answers
   - Schema markup for voice search

5. Conclusion (100-150 words)
   - Summary of key points
   - Clear call-to-action (CTA)
   - Link to registration or contact form

6. Related Posts
   - 3 links to other blog posts
   - Internal linking boost

7. CTA Banner
   - Clear next step for reader
   - Link to relevant service page
```

### 3.2 Heading Hierarchy

- **H1:** One per page, includes primary keyword
- **H2:** 4-6 per post, includes secondary keywords
- **H3:** 2-4 per H2 section, supporting topics
- **H4:** Optional, for detailed subsections

**Example:**
```html
<h1>How to Register as a Nurse with Interim Health</h1>
<h2>Why Register with a Nursing Recruitment Agency?</h2>
<h3>Access to Exclusive Nursing Jobs South Africa</h3>
<h3>SANC Verification Made Simple</h3>
<h2>Step-by-Step Registration Process</h2>
<h3>Step 1: Personal Information</h3>
<h3>Step 2: Professional Qualifications</h3>
```

## 4. SEO Optimization Guidelines

### 4.1 Title Tag Optimization
- **Length:** 50-60 characters
- **Format:** [Primary Keyword] | [Unique Value] | Interim Health
- **Example:** "How to Register as a Nurse | Step-by-Step Guide | Interim Health"

### 4.2 Meta Description Optimization
- **Length:** 155-160 characters
- **Include:** Primary keyword + value proposition + CTA
- **Example:** "Learn how to register as a nurse with South Africa's leading healthcare staffing agency. Get access to locum & permanent nursing jobs nationwide. Join now!"

### 4.3 URL Structure
- **Format:** `/blogs/[primary-keyword-slug]`
- **Example:** `/blogs/how-to-register-as-nurse-south-africa`
- **Rules:** 
  - Use hyphens, not underscores
  - All lowercase
  - Include primary keyword
  - Keep under 60 characters

### 4.4 Image Optimization
- **File Names:** descriptive-with-hyphens.jpg
- **Alt Text:** Include relevant keyword naturally
- **Example:** `alt="SANC verified nurse registration process South Africa"`
- **Compression:** Use WebP format, compress to <100KB
- **Dimensions:** 1200x630px for featured images

### 4.5 Content Length
- **Minimum:** 1,500 words
- **Optimal:** 2,000-2,500 words
- **Maximum:** 3,000 words
- **Why:** Longer content ranks better, provides more value

### 4.6 Keyword Density
- **Primary Keyword:** 1-2% (10-20 times in 2,000 words)
- **Secondary Keywords:** 0.5-1% each (10-20 times each)
- **Natural Integration:** Never force keywords, prioritize readability
- **LSI Keywords:** Use related terms naturally (synonyms, variations)

## 5. Internal Linking Requirements

### 5.1 Required Internal Links Per Blog Post

**Minimum 5 internal links:**
1. **Homepage** (1 link) - Use "Interim Health" or "healthcare staffing agency"
2. **Services Page** (1-2 links) - Use "locum nurses", "permanent placements", "caregivers"
3. **Join/Registration Page** (1-2 links) - Use "register as nurse", "join our network"
4. **Contact Page** (1 link) - Use "contact us", "get in touch"
5. **Related Blog Posts** (2-3 links) - Use descriptive anchor text

### 5.2 Anchor Text Best Practices

**DO:**
- "learn more about our locum nurse placements"
- "register as a nurse with Interim Health"
- "our healthcare staffing solutions"
- "contact our recruitment team"

**DON'T:**
- "click here"
- "read more"
- "this page"
- Exact match keyword stuffing

### 5.3 Link Placement
- Place links naturally within content
- Link to relevant service pages when discussing topics
- Use contextual links (within sentences, not just at the end)
- Balance link distribution throughout the post

## 7. Quality Standards

### 7.1 Content Quality Checklist

**Accuracy:**
- [ ] All facts and statistics are accurate
- [ ] SANC requirements are up-to-date
- [ ] Legal information (POPIA, labour laws) is current
- [ ] Contact information is correct

**Readability:**
- [ ] Clear, concise language
- [ ] Short paragraphs (3-4 sentences max)
- [ ] Bullet points and numbered lists
- [ ] Subheadings every 300 words
- [ ] Reading level: Grade 8-10 (accessible to broad audience)

**Value:**
- [ ] Solves a specific problem or answers a question
- [ ] Provides actionable advice
- [ ] Includes real examples or case studies
- [ ] Offers unique insights not found elsewhere

**Engagement:**
- [ ] Compelling headline
- [ ] Strong introduction hook
- [ ] Clear, logical flow
- [ ] Strong conclusion with CTA
- [ ] Encourages comments/questions

### 7.2 Writing Style Guide

**Tone:**
- Professional yet approachable
- Authoritative but not preachy
- Helpful and supportive
- South African context (use local examples, terminology)

**Voice:**
- Active voice preferred
- Second person ("you") to engage reader
- Inclusive language
- Avoid jargon unless explained

**Formatting:**
- Short paragraphs (3-4 sentences)
- Bullet points for lists
- Numbered lists for processes
- Bold for important points
- Blockquotes for testimonials or key insights

## 8. Blog Creation Checklist

### Before Writing:
- [ ] Select target primary keyword from keyword research
- [ ] Research top 3 competing articles
- [ ] Identify unique angle or value proposition
- [ ] Outline content structure (H2/H3 headings)
- [ ] List 3-5 secondary keywords to target
- [ ] Identify 2-3 internal linking opportunities

### During Writing:
- [ ] Write compelling H1 with primary keyword
- [ ] Include primary keyword in first 100 words
- [ ] Use H2 headings with secondary keywords
- [ ] Write 1,500-2,500 words
- [ ] Include 5+ internal links with descriptive anchor text
- [ ] Add 5-8 FAQ questions with schema markup
- [ ] Include clear CTA in conclusion
- [ ] Optimize images with descriptive file names and alt text
- [ ] Write meta title (50-60 chars) and description (155-160 chars)

### After Writing:
- [ ] Proofread for grammar and spelling
- [ ] Check keyword density (1-2% primary, 0.5-1% secondary)
- [ ] Verify all internal links work
- [ ] Test mobile responsiveness
- [ ] Add schema markup (Article + FAQ)
- [ ] Create featured image (1200x630px)
- [ ] Add to sitemap.xml
- [ ] Share on social media
- [ ] Submit to Google Search Console
